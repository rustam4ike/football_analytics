# Футбольная аналитика

Практическая работа №1 по анализу и прогнозированию данных футбольного клуба.

▶️ **[Открыть блокнот в Google Colab](https://colab.research.google.com/github/rustam4ike/football_analytics/blob/main/practice_1.ipynb)**

**Стек:** Python, pandas, matplotlib, scikit-learn, xgboost

## Данные

Выдуманный датасет `football_dataset.csv` несуществующего клуба: дата, место проведения, доход, расходы,
чистая прибыль, посещаемость, результат матча и турнирная положение.

## Задачи

- Сравнение чистой прибыли домашних и гостевых матчей
- Связь турнирной позиции и прибыли
- Сравнение побед дома и в гостях
- Прогнозирование чистой прибыли моделью XGBRegressor

## Результат

Точность модели (R²): **90.70%**
